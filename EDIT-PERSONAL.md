# Shell · proyecto personal

Este repositorio contiene mi shell para Debian 13 + Umbriel. También contiene la
documentación y las herramientas para instalar el **edit personal de Umbriel**
que vive en:

```text
https://github.com/Gitnameb/umbriel-edit
```

No es un producto oficial de Noctalia ni una versión mejorada de Umbriel. Está
hecho para mi equipo y mi forma de usar el escritorio.

- No hay soporte ni garantías.
- No hay compromiso de compatibilidad con el Umbriel oficial.
- Si alguien lo usa, debe revisar los cambios y asumir el riesgo.
- El proyecto original sigue siendo la referencia.
- El edit se distribuye bajo GPL-3.0 y conserva la atribución y el aviso MIT
  del Umbriel original.

Los detalles del compositor están en `UMBRIEL-EDIT.md`. La instalación está en
`INSTALACION.md`.
